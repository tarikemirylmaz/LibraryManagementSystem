# Library Management System

A Java-based library management system developed using **Object-Oriented Programming (OOP)** principles.

## About the Project

This project simulates a basic library management system where books, users, and library transactions can be managed.

The project was developed to practice object-oriented programming concepts and organize different responsibilities using separate Java classes.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Collections
- Basic Data Management

## Project Structure

- `Book.java` - Represents books in the library
- `User.java` - Represents library users
- `Library.java` - Handles the main library operations
- `Transaction.java` - Represents library transactions
- `FinalProject.java` - Main entry point of the application

## Features

- Book management
- User management
- Library transaction management
- Object-oriented class structure
- Separation of responsibilities between classes
